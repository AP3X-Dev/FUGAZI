# Code of Conduct

The Fugazi project adopts the **Contributor Covenant** as its code of conduct.
The full text, version 2.1, is published at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Summary

Contributors and maintainers commit to making participation in this project a
harassment-free experience for everyone, regardless of background, identity,
or experience level. We expect respectful, welcoming, and constructive
behavior in all project spaces — issues, pull requests, discussions, and any
official channels.

Behavior that is unacceptable includes harassment, derogatory comments,
personal attacks, and unwelcome sexual attention. The full Covenant text at
the link above is the authoritative source for examples and definitions.

## Reporting

To report behavior that violates this code, contact the maintainers at:

> conduct@fugazi.dev

Reports are reviewed confidentially. The maintainers will respond within five
business days and may take any action they deem appropriate, including
warnings, temporary bans, or permanent bans from project spaces.

## Scope

This code applies to all project spaces and to public spaces when an
individual is representing the project or its community.
